# NovaBar 0.4
Windows 11 Tauri dock. Includes installed app search, real media artwork when available, window switching, native quick settings and notifications, monitor selection, fullscreen hiding, crash recovery helper, experimental Windows AppBar work-area reservation, weather and appearance settings. One dock at a time; no third-party tray icon hosting. Native Windows runtime testing required, especially AppBar behavior, monitor changes and crash recovery. No AI tracking.
