# NovaBar 0.4
Windows 11 Tauri dock. GitHub Actions builds the unsigned installer. Features: real media artwork when available, installed app search, window switching, native quick settings and notification access, monitor selection, fullscreen visual hiding, crash recovery helper, weather and appearance settings. Limitations: one dock at a time, no third-party notification-area icon hosting, no work-area reservation yet; fullscreen hiding is visual only. Windows runtime testing required. No AI tracking.
